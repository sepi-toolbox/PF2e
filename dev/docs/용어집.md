## 용어 결정 원칙

1. **이 문서 > 마스터 용어집 > PF2e-KR 오버레이** 순서로 우선한다.
2. 여기 없는 용어는 ① 마스터 용어집 → ② PF2e-KR → ③ 기존 코퍼스 지배 표기 순으로 조회하고, 새로 결정한 용어는 이 문서에 추가한다.
3. **대량 기계 치환은 이 문서에 명시된 용어만.** 명시 안 된 용어의 일괄 변경은 사용자 승인 필수.
4. 엔티티 고유명(주문·재주·아이템·신격 이름)은 이 문서 대상이 아님 — `data/override/<cat>.json`이 정본.
