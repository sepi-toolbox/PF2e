## 적용 원칙
1. **유형어 정본(강제)**: Elixir=엘릭서, Potion=물약, Oil=기름, Snare=올가미, Mutagen/Serum=혈청, Vial=약병. 등급=최하급·하급·보통·중급·상급·최상급.
2. **개념 동일 → 통일**: 효과(effects)는 원본(장비/주문/재주)을 따름. 행동↔재주(재주가 행동 부여), 주문↔재주(재주가 주문 부여)는 하나로.
3. **의역 > 음역**(일반명사): 크리스탈→수정, 브레스→숨결, 트루스피치→진실의 언어. 단 고유명사·용어집 지정 유형어는 음역.
4. **정본 방향 수동 교정**: `Concealed`=**은폐**(사용자 용어집 정본, 조건 유지 / 효과를 은폐로) · `Aerekostes`=**아에레코스테스**(신격 고유명사 정본 / 장비를 맞춤). ← 에이전트가 방향 반대로 잡아 병합 단계에서 정정.
5. 깨진 이름 교정: "마법 {숨기"→마법 가죽, "서리 폭탄"→서리 약병, "페츨링 팔찌"→매혹적인 팔찌.
